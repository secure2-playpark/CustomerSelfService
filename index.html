HOW IT WORKS

แจ้งปัญหาง่าย ๆ ใน 3 ขั้นตอน

01●

เลือกประเภทปัญหา

เลือกหมวดที่ตรงกับปัญหาเพื่อให้ทีมงานคัดแยกเคสได้เร็วขึ้น

02●

กรอกรายละเอียด

ระบุข้อมูลติดต่อ Account/Player ID และอธิบายอาการที่พบให้ชัดเจน

03●

รับ Ticket ID

ระบบจะออกเลขอ้างอิงสำหรับติดตามสถานะและข้อความตอบกลับจากทีมงาน

FAQ

ก่อนส่งคำร้อง

ควรใส่ข้อมูลอะไรในรายละเอียดปัญหา?

ระบุสิ่งที่กำลังทำก่อนเกิดปัญหา วันเวลาโดยประมาณ ข้อความ Error และขั้นตอนที่ลองแก้ไปแล้ว เพื่อช่วยให้ตรวจสอบได้เร็วขึ้น

ระบบต้องการ Password หรือ OTP หรือไม่?

ไม่ต้องกรอก Password, OTP, Recovery Code หรือข้อมูลลับอื่นใดในฟอร์มแจ้งปัญหา

ติดตามสถานะอย่างไร?

ใช้ Ticket ID ที่ได้รับหลังส่งคำร้องร่วมกับ Email เดียวกับที่ใช้แจ้งปัญหาในหน้า “ติดตามคำร้อง”
